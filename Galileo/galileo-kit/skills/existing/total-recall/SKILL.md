# Total Recall

A singularity looks like it came from nowhere. It never did: there is a first instance, a lineage of mutations, and a set of preconditions that made the moment possible. Total Recall runs time backward until the thing dissolves into its parts.

## Define the singularity first

State precisely what emerged, when it became widely visible (the **visibility point**), and in which form. Forms have separate trails — the *term*, the *idea*, the *capability*, the *deployment* — and they often originate in different places and decades. Trace each one separately.

## Roam — widening rings, backward

1. **Visibility point** — the moment of mass attention, and who amplified it.
2. **Pre-visibility** — niche coverage, trade press, forums, conference talks, preprints.
3. **Formal record** — patents (priority dates), papers (first submission), filings, standards drafts, legislative records, archived pages (earliest web-archive snapshots).
4. **Precursors** — older work with the same mechanism under a different name. Search by mechanism, not by label: labels arrive late.
5. **Conditions** — what had to exist first: a cost curve crossing, an enabling technology, a policy change, resource access, a person moving between institutions.

Use date-bounded queries; search in the original language where the origin is likely non-English; prefer primary sources. Every "first" is provisional — actively hunt for an earlier instance instead of collecting support for the first one found.

## Output — Origin Dossier

- **Singularity** — precise statement + visibility point.
- **Earliest verified instance** — date, place, actor (institution or public role), source link, confidence.
- **Lineage** — the chain of mutations from origin to visibility; each step with date, source and what changed.
- **Conditions of possibility** — preconditions ranked by how binding they were. Use min() logic: which one, if absent, kills the emergence entirely?
- **Geography of conception** — where it was conceived vs built vs scaled.
- **Open threads** — where the trail goes cold, and which source would extend it.
- **Sources** — linked list.

## Discipline

- "Roaming the clouds" means the open web, public archives, registries and publications — never anyone's private storage, accounts or systems.
- Trace ideas, works and institutions. People appear only in their public role in the lineage; don't build profiles of private individuals.
- Simultaneous independent origins are common. Report them as such rather than forcing a single winner.
- Origin myths are part of the lineage — include them, labeled as myth vs record.
