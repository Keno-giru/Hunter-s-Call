# Second Source

One source can be wrong, biased or misread. Two sources that copied each other are still one source. The rule borrowed from journalism and intelligence work: a load-bearing claim needs two independent confirmations, or it gets reported as single-sourced.

## Independence test

Two sources are independent when they reached the claim separately. Check:

- Do they cite each other, or the same upstream document (one press release, one wire story, one Wikipedia line)? Then they count as one.
- Different organisations, authors and methods?
- Is either a primary source (the filing, dataset, statute, transcript, paper)? A primary source plus one independent secondary source is strong.
- Does either have an interest in the claim being true? Interested sources need an uninterested confirmation.

## Source strength, roughly

Primary documents and official data > peer-reviewed work > established reporting with named sourcing > secondary summaries and encyclopaedias > blogs, forums and social posts.

## Procedure

1. List the load-bearing claims.
2. For each, find a first source, then search specifically for an independent second one.
3. Trace both upstream until you know where each got it.
4. Classify: **confirmed** (two independent), **single-sourced** (one, or several copies of one), **conflicting** (sources disagree).
5. Write accordingly: confirmed claims as fact; single-sourced claims attributed ("according to …"); conflicts shown with both versions.

## Output

| Claim | Status | Source A | Source B | Note |
|---|---|---|---|---|

Or, in prose answers, attribute single-sourced claims in the sentence itself.

## Rules

- Circular reporting is the main trap: many outlets repeating one origin is still one source.
- Do not drop a true but single-sourced claim; attribute it.
- When the stakes are high and only one source exists, say so plainly.

## Handoffs

Claims Ledger records the result (Sourced with confidence high for confirmed, medium or low for single-sourced).
